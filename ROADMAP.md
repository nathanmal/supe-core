# Roadmap — supe-core

Candidate features for this package, to be prioritized and scoped properly later. Nothing here is committed — this is a parking lot, not a sprint plan.

Nothing currently planned — `supe-core` is intentionally minimal (loader, registry, container, contracts). Any future addition here should be weighed hard against "does this belong in a module instead?" before landing in the core package, since everything here is a dependency of every module.

See `PROGRESS.md` in this directory for this package's change history and `../supe/TESTING.md` for its testing setup.
